# kubejs/data

Loaded by KubeJS as a datapack. Used for recipe formats that KubeJS has no helper for.

NOTE: the Forbidden & Arcanus 1.16 Hephaestus Forge has only 6 pedestals: rituals can use at most 6 inputs (slots 0-5).

- `titanmodpack/hephaestus_forge/rituals/` - Forbidden & Arcanus Hephaestus Forge rituals (one file per ritual).
  - `forge_upgrade_tier_2..5.json`: upgrade rituals adapted from Forbidden & Arcanus 1.21.1 (result = TitanOres
    Forge Upgrade item; right-click the forge with it). Essences scaled to fit the current tier's limits in 1.16.
  - `source_crystal_*_heart.json`: Source Crystal (needs tier 3+).
